# Xandeum Analytics: an analytics dashboard that turns raw pNode network data into plain answers for node operators.

- When: December 2025 to January 2026
- Type: Superteam bounty, designed and built
- Case study: https://rayasurya.com/projects/xandeum-sprint/

**What Raya built.** A Next.js dashboard for Xandeum storage-node operators: a node registry, node details, a network dashboard, a leaderboard and a storage map. First built in a 48-hour sprint, then refined until January 2026.

**Signature detail.** One health score from four weighted signals: uptime 35% (a sigmoid curve), storage 30% (a log curve), credits 20% (against the top earner) and version 15% (minus 30 points per version behind). 70 or more is healthy.

**AI.** "Ask AI" sends the question to Gemini 1.5 Flash together with the dashboard's live state, so answers are about the current network.
